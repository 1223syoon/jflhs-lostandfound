### 2. ADD ITEM STATUS MANAGEMENT

Each lost-and-found item must have these two statuses:

- "보관 중"
- "찾아감"

The default status when a new item is registered should be:

"보관 중"

In the admin dashboard, add a button or control that allows an administrator to change the status.

For example:

보관 중 → 찾아감

When an item has been returned to its owner, the administrator can change it to "찾아감".

The status change must be saved to the database and remain after refreshing the page.

### 3. STUDENT PAGE STATUS

- Items with status "보관 중" should be displayed normally.
- Items with status "찾아감" should clearly show a "찾아감" badge.

Do not delete the item automatically when its status changes.

Students should still be able to see that the item was found and has already been claimed.
